# rem-ram.me — Rem & Ram Fan Archive

Bilingual Spanish / English static fan site for GitHub Pages.

## Local preview
Open `index.html`, or run `python -m http.server 8000` from the repository root.

## GitHub Pages
1. Open **Settings → Pages**.
2. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Set custom domain to `rem-ram.me`.
4. Configure the DNS records at your registrar using GitHub's current documentation: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
5. After DNS verification, enable HTTPS.
