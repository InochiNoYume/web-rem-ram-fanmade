Revisión editorial

  • Verificar hechos, nombres y cronología.
  • Añadir fuentes por ficha.
  • Separar anime, novela ligera y web novel.
  • Revisar traducciones ES/EN.
  • Marcar spoilers.

Accesibilidad

  • Contraste y foco visible.
  • Etiquetas en controles.
  • Texto alternativo en imágenes.
  • Respeto a movimiento reducido.
  • Pruebas de teclado y lector de pantalla.

Rendimiento

  • Probar móvil, tableta y escritorio.
  • Comprobar navegadores principales.
  • Evitar recursos pesados innecesarios.
  • Revisar errores de consola.
  • Verificar enlaces externos.

Publicación en GitHub Pages

  1. Abrir Settings → Pages.
  2. Seleccionar Deploy from a branch.
  3. Elegir main y /(root).
  4. Verificar rem-ram.me y DNS.
  5. Activar HTTPS cuando GitHub lo permita.
